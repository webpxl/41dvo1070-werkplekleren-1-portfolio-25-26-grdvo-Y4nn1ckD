WPL1 - Digitale Vormgeving

Situering binnen WPL1

Een reflectie op mijn ontwikkeling binnen de vier hoofdrollen van digitale vormgeving.

Rol 1: Creatieve vormgever (ORL 1-4)

Binnen de rol van Creatieve Vormgever heb ik het gevoel dat ik al goed op weg ben. Wanneer ik een briefing krijg, heb ik meestal vrij snel een idee van hoe ik de opdracht wil aanpakken en hoe ik het project tot een goed einde kan brengen. Op het vlak van UI-design ben ik sterk gegroeid, vooral dankzij het vak UI Design 2. Door dit vak is niet alleen mijn kennis verbeterd, maar is ook mijn interesse in UI-design nog groter geworden. Branding is een onderdeel waarin ik mij vrij sterk voel en waar ik graag mee bezig ben. Wanneer het aankomt op UX-design en het werken met data merk ik wel dat dit nog beter kan. Dit zijn punten waarin ik mezelf verder wil ontwikkelen en waarin ik nog veel kan bijleren.

Rol 2: Front-end Ontwikkelaar (OLR 5-7)

Op het gebied van front-end ontwikkeling vind ik dat ik nog veel kan bijleren. Wanneer ik code bekijk, begrijp ik meestal wat het doet, maar het zelf schrijven ervan blijft soms moeilijk, vooral bij JavaScript. Toch heb ik vaak snel een duidelijk beeld van hoe ik een idee wil opbouwen en hoe het er uiteindelijk moet uitzien. Ik probeer mijn werk stap voor stap aan te pakken en sectie per sectie uit te werken, zodat alles overzichtelijk blijft en niet in de war geraakt.

Rol 3: Communicator / Teamspeler (OLR 8-9)

Zelf vind ik dat ik sterk ben in het samenwerken met anderen. Bij groepsopdrachten probeer ik er vanaf het begin voor te zorgen dat er een duidelijke en vlotte manier van communiceren is. Ik vind het belangrijk dat alles vanaf het eerste moment goed besproken wordt. Het opnemen van een echt leidende rol is iets waar ik nog in kan groeien. Ik werk het liefst in een groep waarin iedereen evenveel inspraak heeft en waarin beslissingen samen genomen worden van begin tot het einde van het project.

Rol 4: Levenslang Lerende (OLR 10-12)

In mijn vrije tijd leer ik graag bij. Af en toe zoek ik tutorials op om beter te begrijpen hoe ik bepaalde dingen kan aanpakken waar ik nieuwsgierig naar ben. Ik sta altijd open voor feedback en vraag regelmatig aan vrienden en familie wat zij van mijn werk vinden, daarnaast stap ik ook vaak naar docenten toe met vragen. Ik heb soms last van faalangst, maar die is door de jaren heen al sterk verminderd. Ik blijf hier bewust aan werken en probeer mezelf steeds meer vertrouwen te geven in mijn eigen kunnen.

AIM-reflectie op voorbije periode

Tijdens de periode van WPL1 heb ik al een kleine inkijk gekregen over hoe je dingen die je geleerd hebt in de opleiding, zou moeten toepassen in het werkveld. We hebben geleerd hoe je op een goede manier feedback kan geven/krijgen in teamverband, wat zeker helpt in het uitvoeren van de rest van de opdracht. Ook hebben we ervaren hoe het is om in een korte periode nieuwe mensen te leren kennen, en daar dan mee samen mee te moeten werken.

Wat vond je een bijzonder positief element van Werkplekleren 1?

Ik vond de portfolio opdracht een enorm leuk project om te maken. Bezig zijn met de code vond ik minder, maar het idee daadwerkelijk op de website zien verschijnen blijft toch wel leuk om te zien. Ook oudere gemaakte projecten terug benoemen/zien is leuk.

Wat vond je een minder leuk element van Werkplekleren 1?

Ik vond de dashboard opdracht minder leuk. Ik merkte geen moeilijkheden, maar ik merkte dat ik minder snel geïnteresseerd was bij deze opdracht, dan bij andere.

Welke nieuwe inzichten neem je mee uit Werkplekleren 1?

Door de sprekers die in het begin van het semester, heb ik een heel goed idee gekregen over hoe de geleerde dingen toegepast moeten worden in het werkveld. Ook werken in kleine groepjes lijkt me persoonlijk fijner, dan grote groepen/organisaties.

Wat zou je een persoonlijk succes noemen tijdens Werkplekleren 1?

Ik zou mijn portfolio website toch het grootste succes noemen van dit vak. Ik ben echt tevreden met hoe het project uiteindelijk geworden is, en ik hoop deze nog lang te kunnen gebruiken/updaten.
